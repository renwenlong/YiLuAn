## 注意事项（胡桃 swap 时）

1. **%% escape**：retufer rules 段含百分比 `30%%`、`50%%`、`24%%` 等，Python format string 里需 `%%` escape（reportlab Canvas `drawString` 不走 % format，但保持 `%%` 安全；如直接展示 `%` 可改回单 `%`）
2. **行宽控制**：每段已按 reportlab Canvas 默认行宽（A4 + 5mm margin）手动换行；如胡桃后续切 `Platypus.Paragraph` 自动 justify，把 `\n` 删除即可
3. **AC-F8-6 职业背书禁词检查**：§3 末段明示「不就职业身份背书」≠ 禁词命中（不出现「已护士/已医生/资格/执业」原词）
4. **未填占位 3 处**仍在（平台运营主体名称 / 客服电话 / 司法管辖地），不在本文案 4 段范围内，等帝君拍板补齐后 PM 走小 PR amend
