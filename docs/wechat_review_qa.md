本文整理微信小程序审核过程中常见的 5 类问题与官方回答稿，供提审 / 复审环节直接复用。回答稿均经法务初核，正式提交前请 PM 二次确认。

## Q1：为什么需要医疗类目？

**回答稿**：
医路安提供"陪同就医"服务，覆盖患者从挂号、引导、候诊、取药到离院的全流程陪同，属于围绕医疗机构发生的辅助服务。根据微信开放平台《非个人主体小程序开放的服务类目》，"医疗 - 互联网医院 / 医院 / 医疗服务类"是与本服务最相关的类目；医路安**不提供**任何诊疗、用药建议或医疗意见，所有医疗判断与决策由具备执业资质的医疗机构和医师作出。本服务定位为"非医疗性陪诊服务"，故选择医疗类目下的"陪诊 / 就医辅助"分支以匹配实际业务范围。

## Q2：用户隐私如何保护？

**回答稿**：
我们已制定完整的《医路安隐私政策》（小程序内"我的 → 法律协议 → 隐私政策"可查看），明确披露收集的信息类型、用途、共享范围、存储期限、用户权利与申诉渠道。技术层面采取以下措施：

- 全链路 HTTPS / TLS 1.2+ 传输
- 手机号、身份证、紧急联系人等 PII 字段在应用层使用 AES-256-GCM 加密落库（参见 PR #48 PII 加密改造）
- 访问最小权限 + 后台审计日志 + 双因素登录
- 资金 / 对账数据按《电子商务法》《支付服务管理办法》要求保留 5 年（详见隐私政策第 5.3 节）

用户可在小程序内随时查看 / 更正 / 申请删除个人信息；账号注销请求确认后 30 天内完成数据删除或匿名化（紧急呼叫数据立即硬删，详见 ADR-0029）。

## Q3：支付链路是否合规？

**回答稿**：
本小程序的支付通道使用**微信支付**官方能力，通过持牌商户号（受理商户编号在 B-01 工单中登记）接入，遵循《非银行支付机构网络支付业务管理办法》《支付服务管理办法》等法规要求。技术架构遵循 ADR-0032《资金对账机制》：

- 支付回调通过 RSA-SHA256 验签，确保通知来源真实
- 服务端不存储银行卡号、CVV、密码等敏感支付要素，相关信息由微信支付直接收集与处理
- 全量支付 / 退款流水写入 wallet_ledger 与 reconciliation 体系，T+1 cron + 增量队列双轨对账
- 资金类数据保留 5 年，满足监管可追溯要求

提审阶段如审核员需查看真实支付流程，可使用提交材料中的演示账号 + 演示订单完成 0.01 元支付测试。

## Q4：客服联系方式

**回答稿**：
医路安在小程序内提供以下客服触达入口：

- 小程序内：「我的 → 联系客服」打开 admin 侧 H5 客服会话（微信侧通过 `open-type="contact"` 唤起）
- 客服邮箱：`privacy@yiluan.com`（隐私 / 投诉类）
- 客服响应时限：**15 个工作日内**
- 紧急情况：陪诊订单进行中可在订单详情页"一键紧急联系"触发紧急联系人通知

后台客服由 admin H5 客服工作台统一接入，所有会话留痕用于纠纷取证（参见隐私政策第 2.7 节）。

## Q5：内容审核机制

**回答稿**：
医路安对平台产生的两类核心内容均设置审核机制：

1. **陪诊师资质审核**：陪诊师注册后需提交真实姓名、身份证、健康证、培训证书等资质材料；由后台运营人工审核通过后方可对患者展示，并对身份证号等 PII 字段进行加密存储与脱敏展示（仅展示昵称、头像、星级、服务区域、技能标签）。
2. **订单流转审核**：订单从创建、匹配、履约、完成到评价的全流程均有状态机校验与服务端事务保护，关键节点（接单、完成、纠纷、退款）均写入审计日志；用户主动上传的就诊凭证、纠纷举证材料经服务端识别与人工抽检；聊天文字 / 图片 / 语音由后台留痕，运营值班对违规内容（医疗广告、违规导流、隐私泄露等）执行下架与账号处置，并配合微信平台的内容安全接口（`security.msgSecCheck` / `security.imgSecCheck`）做实时机审。

如审核员发现具体违规内容，请通过审核备注反馈，我们将按内容安全 SOP 在 24 小时内闭环处置。
